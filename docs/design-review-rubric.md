# Design Review Rubric (DR #1)

> Recreated from the W5 deck, slide 33, because the bundle file
> `AI-RAG_W5_design_review_rubric.md` was not available. The deck shows Levels
> 1, 3 and 4 only; **Level 2 is not in the deck**. Ask the instructor for the
> full 5×4 table before DR #1.

Five dimensions × four levels. DR #1 is not pass/fail: it marks your trajectory.
The passing bars are at DR #3, #5 and #7.

| Dimension | Level 1 — Poor | Level 2 | Level 3 — Good | Level 4 — Excellent |
|---|---|---|---|---|
| Problem clarity | User unclear | *(not in deck)* | Use case named, sponsors listed | Stakeholder map specific + measurable |
| Architecture | Hand-wavy | *(not in deck)* | Diagram + ADR exists | Diagram + ADR + tradeoffs articulated |
| Evidence | Demo only | *(not in deck)* | Demo + tests passing | Demo + tests + eval numbers |
| Decisions | Implicit | *(not in deck)* | Recorded in ADR | ADR + reasons + counterexamples |
| Defensibility | Defensive | *(not in deck)* | Answers most challenges | Welcomes challenges; updates ADR live |

**DR #1 format (15 min):** present for 5 min (1-pager + demo, three slides
max) · peer challenge for 5 min (two assigned peers) · instructor synthesis
for 3 min · commit a one-line ADR update live for 2 min.
